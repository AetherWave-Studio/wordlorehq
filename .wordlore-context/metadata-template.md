# Wordlore Episode Metadata Template

## Title pattern (locked)

`[WORD] literally means "[origin meaning]"`

This pattern is intentional and consistent across the series. It:
- Includes the word for SEO and recognition
- Delivers the payoff in the title (matches the brand's "honest reveal" voice, anti-clickbait)
- Creates series identity — viewers see the format and know what to expect
- Mirrors the "is, literally," connector inside the videos

### Examples in use

- NIGHTMARE literally means "demon attack"
- GOODBYE literally means "God be with you"
- DISASTER literally means "bad star"
- ROBOT literally means "forced labor"

Length: keep under 60 characters for mobile feed display when possible.

## Per-platform structure

### YouTube (and Facebook)

```
[1-2 sentence hook from journey content]

Every word has a story.

#etymology #wordhistory #shorts #[word] #language
```

3-5 hashtags max. `#shorts` is essential.

### TikTok

```
[Punchier 1-line hook] [optional restrained emoji]

#etymology #wordhistory #fyp #learnontiktok #wordsoftiktok #[word] + 3-4 word-specific tags
```

8-15 hashtags. Mix topic + trending + word-specific. The emoji rule is restrained — at most one understated icon per post, never decorative spam.

### Instagram Reels

```
[2-3 sentence version of journey]

#etymology #wordhistory #reels #language #englishlanguage + 4-5 word-specific tags
```

5-10 hashtags. Mix popular + niche.

### X / Twitter

```
[One-line provocation + payoff]

youtube.com/@wordlorehq
```

Hashtags don't move the needle on X. Skip them or use one. Cross-link to YouTube is the priority.

## Pinned comment (YouTube — high-value real estate)

Format:

```
Bonus: [related etymology fact from another word]. // Next word: [NEXT WORD]
```

The bonus fact rewards comment-scrollers with extra payoff and reinforces the "every word has a story" thesis by gesturing at adjacent etymologies. The next-word tease drives return viewers.

### Examples

NIGHTMARE pinned comment:
> Bonus: "sleep paralysis" was called *being ridden by the mare* for centuries before doctors gave it a medical name. The horror predates the diagnosis. // Next word: GOODBYE

GOODBYE pinned comment:
> Bonus: French *adieu* literally means *to God* — same blessing, different language. So does Spanish *adiós* and Italian *addio*. Half of Europe is still quietly praying when they leave a room. // Next word: DISASTER

## Anti-patterns

- ❌ Emojis in YouTube titles (anti-brand)
- ❌ All-caps phrases in descriptions (only the hero WORD itself uses caps)
- ❌ Generic hashtags like `#love` `#life` `#viral`
- ❌ Clickbait phrasing ("You won't believe...", "I had no idea...", "Wait til you see what...")
- ❌ More than one emoji per caption, even on TikTok/IG
